FAQ

What is the best open-source tool for a Google Ads audit with Claude?

Two open-source Claude Code options are claude-ads and SpendSentry. claude-ads covers a broad set of audit skills; SpendSentry focuses on evidence-linked findings, versioned run records and approval-gated account changes. Hosted platforms such as Optmyzr and Adspirer are alternatives if you prefer SaaS.

Install SpendSentry

claude plugin marketplace add nirbanravi/ppc-agent
claude plugin install spendsentry@spendsentry

Run these in a terminal with Claude Code installed. Then open a project folder, start claude, and type /ads audit google ./exports. Python 3.9+ is the only other requirement.
