AI Meta Ads audit (Facebook & Instagram) with Claude Code

Audit Meta Ads from an export: CPA and ROAS against target, frequency and creative fatigue, zero-conversion ad sets and tracking gaps, each with the evidence behind it.

What to export from Ads Manager

  • Campaign and ad set level: Amount spent, Impressions, Reach, Frequency, Link clicks, a named conversion event (Purchases, Leads) and its conversion value.
  • Break it down by Day. Without daily rows, the tracking-break and trend checks cannot run, and the report will say so.
  • Optional: an ad-level export for creative fatigue.

FAQ

How do I audit Meta Ads with AI?

Export a campaign and ad set report from Ads Manager with spend, impressions, reach, frequency, link clicks, a named conversion event and its value (ideally broken down by day), then run /ads audit meta ./exports in Claude Code with SpendSentry.

Why should I avoid the 'Results' column?

In Meta Ads Manager, 'Results' counts whatever event each ad set optimises for, so it can mix purchases, leads and other events. SpendSentry warns when it sees it. Export a named event such as Purchases or Leads instead.

Can SpendSentry change my Meta campaigns?

Not without your approval. Meta's official Ads MCP server can create and edit campaigns, so SpendSentry treats every write tool as gated: it runs only when it matches a change you approved with a one-time code.
